# Сытный край (Hearty Lands)

Мод о еде для **Minecraft 1.21.1** на **NeoForge**. Опоры: кухня, питание, свежесть.
Farmer's Delight не нужен (совместимость с ним появится позже как необязательная).

## Что уже есть (версия 0.1.0)

| Еда | Голод | Как получить |
|---|---|---|
| Яичница | 4 | Яйцо в печке, коптильне или на костре |
| Овощное рагу | 9, возвращает миску | Миска + морковь + печёный картофель + свёкла + коричневый гриб |
| Ягодный пирог | 7, Скорость I на 20 с | 2 сладкие ягоды + сахар + яйцо + пшеница |
| Сэндвич с мясом (×2) | 11 | Хлеб / любое жареное мясо / хлеб (столбиком) |

Все предметы лежат в своей вкладке творческого режима «Сытный край». Текстуры пока заглушки.

## Как запустить

Нужна Java 21 (JDK). В папке проекта:

- Windows: `gradlew.bat runClient`
- macOS / Linux: `./gradlew runClient`

Первый запуск качает Minecraft и NeoForge, это займёт несколько минут.
Готовый `.jar` мода собирается командой `gradlew build` и лежит в `build/libs/`.

В IntelliJ IDEA: «Open» → выбрать папку проекта, дождаться загрузки Gradle, запустить конфигурацию `Client`.

## Где что лежит

- `src/main/java/.../registry/ModFoods.java` — сытность и эффекты еды
- `src/main/java/.../registry/ModItems.java` — список предметов
- `src/main/resources/assets/heartylands/` — переводы, модели, текстуры
- `src/main/resources/data/heartylands/recipe/` — рецепты
